## Synthetic enterprise-to-equity bridge

The filing provides cash and debt inputs, but no enterprise-value assumption. Using the filing's debt definition, the bridge is:

```text
Enterprise value
Less: total debt including current maturities     ($8,946.6m)
Add: cash and cash equivalents                      $198.6m
-------------------------------------------------------------
Equity value                                      EV - $8,748.0m
```

### Calculation

```text
Net debt = total debt - cash
         = $8,946.6m - $198.6m
         = $8,748.0m

Net debt per diluted weighted-average share
         = $8,748.0m / 547.2m
         = $15.99 per share
```

Therefore, for any selected enterprise value expressed in millions:

```text
Equity value = Enterprise value - $8,748.0m
Implied equity value per diluted share = (Enterprise value - $8,748.0m) / 547.2m
```

## Interpretation and limitations

- The $8.748bn net-debt figure is a **mechanical bridge input**, not an assessment of leverage sustainability or fair value.
- The debt definition includes capital lease obligations. Any valuation using a different lease convention must treat enterprise value, debt, and operating metrics consistently.
- The $198.6m cash balance is assumed fully available to offset debt for this preliminary calculation. Restricted-cash availability needs confirmation for a final valuation.
- Diluted weighted-average shares are an annual EPS measure, not necessarily the current fully diluted share count required for a valuation-date price target.
- A complete equity valuation still requires a valuation-date share price, market capitalization, enterprise value, a fully diluted share count, and forward operating and cash-flow analysis.
