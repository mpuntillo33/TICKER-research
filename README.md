# Project 2 — Portfolio Readiness

Built with AI assistance for education only; this is not investment advice.

This repository's reproducible Project 2 readiness check is in [Lab 20](Lab%2020/README.md). From the repository root, run:

```powershell
python "Lab 20/readiness.py"
```

The command prints the baseline constrained allocation, mandate verdicts, and the Project 2 decision. To reproduce the locked changed-input run, use `python "Lab 20/readiness.py" --equity-return 7.0`.

The visible baseline and changed-input outputs are stored in `Lab 20/output/`; the decision memo and validation record are in `Lab 20/docs/`.
