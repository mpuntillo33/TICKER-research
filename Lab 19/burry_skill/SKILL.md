# Burry panel skill

Use only `legend_panel.py`'s printed 10-K facts. Do not fill gaps with a proxy or estimate.

1. Run the script before writing a memo.
2. Check whether operating cash flow is at least net income in every one of the five years.
3. Check whether latest liabilities are no more than twice latest equity.
4. Preserve `not found` and `not known`, and use only the script's generated verdict and printed numbers.
