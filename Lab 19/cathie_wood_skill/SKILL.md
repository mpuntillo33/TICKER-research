# Cathie Wood panel skill

Use only the facts printed by `legend_panel.py`. Do not fetch a different source, estimate a missing value, or introduce a number that is not in the output.

1. Run `python legend_panel.py TICKER --output TICKER_legend_panel.json` using a truthful SEC User-Agent.
2. Read the `Cathie Wood` checks and printed five-year fact table.
3. Write the Cathie Wood memo from printed numbers only. Keep `not found` and `not known` unchanged.
4. The growth check is `(last revenue / first revenue) ** (1/4) - 1`; select its threshold with `--growth-threshold` (the benchmark uses 15%; the recorded probe keeps 5%). The latest-year R&D check is 5% of revenue.
5. State the verdict generated by the code; this is a quality screen, not investment advice.
